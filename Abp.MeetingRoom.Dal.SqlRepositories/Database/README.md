# SQL Server database scripts

Усі SQL-файли застосунку знаходяться в одній папці `Scripts` і впорядковані
числовими префіксами за залежностями:

- `001`–`004` — таблиці;
- `005`–`007` — індекси;
- `008`–`009` — table types;
- `010` — функція розрахунку вартості;
- `011`–`013` — тригери;
- `020`–`025` — процедури кімнат;
- `030`–`033` — процедури бронювань;
- `040`–`042` — процедури звітів;
- `050` — початкові дані;
- `090` — перевірка стану БД;
- `100` — повне ручне розгортання для вже створеної схеми й таблиць.

Для поточної бази відкрийте `Scripts/100-Complete-Database.sql` у SSMS,
виберіть базу `rg-academy-6` і виконайте весь файл. Це автономний T-SQL-скрипт:
SQLCMD Mode не потрібен. Він не видаляє схему або таблиці.

Окремі numbered-файли є вихідними SQL-об'єктами та можуть виконуватися вручну
за їхнім номером. Entity Framework Core migrations і DbUp не використовуються.
